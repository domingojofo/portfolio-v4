# portfolio-v4

Hero experiments for the next version of the portfolio.

- `hero-tunnel.html` — tunnel carousel hero: cards on a curved wall, bottom-aligned on one baseline, infinite scroll. Headline words drop in small, scramble, and jump to full size (Motion 12 from CDN). Add `?final` to the URL to skip the intro.
- `index.html` — previous hero ("Relentlessly Collaborative" typing + grid lines).
- `portfolio/` — Next.js app snapshot carried over from portfolio-v3.

Open the HTML files directly in a browser, or serve the folder: `python3 -m http.server 8000`.

Swap the work images in the `WORK` list at the top of the script in `hero-tunnel.html`.
